## 改进方案

### 命名格式设计

**新格式：** `.session-diary-YYYY-MM-DD-HHMM-topic.md`

**示例：**
```
.session-diary-2026-04-26-1918-intelligent-loading-complete.md
.session-diary-2026-04-26-1915-intelligent-loading-optimization.md
.session-diary-2026-04-26-1904-sessionstart-implementation.md
```

**格式说明：**
- YYYY-MM-DD：年月日（2026-04-26）
- HHMM：时分（24小时制，1918 = 19:18）
- topic：主题关键词（简短描述）
- 不用冒号：避免某些系统兼容性问题

### 时间精度选择

**为什么精确到分钟：**
- 同一小时内多次会话可以区分
- 文件名不会过长（HHMM只占4字符）
- 足够精确，不需要秒数（避免过长）

### 2. 批量重命名现有文件

**重命名脚本：**
```bash

    MTIME=$(stat -c '%y' "$file")
    TIME_PART=$(echo "$MTIME" | awk '{print $2}' | cut -c1-5 | tr -d ':')
```

## 技术细节

### 时间提取方法

**从文件修改时间提取：**
```bash
MTIME=$(stat -c '%y' "$file")
# 输出：2026-04-26 19:18:47.123456789 +0800

# 提取时分（19:18 → 1918）
TIME_PART=$(echo "$MTIME" | awk '{print $2}' | cut -c1-5 | tr -d ':')
# 输出：1918
```

**分解步骤：**
1. `awk '{print $2}'` - 提取时间部分（19:18:47...）
2. `cut -c1-5` - 截取前5字符（19:18）
3. `tr -d ':'` - 删除冒号（1918）

### 自动重命名判断

**检测文件名是否已有时分：**
```bash
if [[ ! "$NEW_DIARY" =~ -[0-9][0-9][0-9][0-9]- ]]; then
    # 文件名中没有4位数字（时分），需要添加
fi
```

**正则解释：**
- `-[0-9][0-9][0-9][0-9]-` - 匹配"-1918-"这样的时分部分
- 如果没有匹配，说明文件名只有日期
