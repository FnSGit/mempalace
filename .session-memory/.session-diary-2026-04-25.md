# SQLite数据库损坏调查 - 2026-04-25

## 关键发现

**跨进程并发写入（最高风险）**
- MCP server (mcp_server.py:106-211) + CLI mine (miner.py) + CLI sweep (sweeper.py:251) 同时写入 chroma.sqlite3
- 无跨进程锁保护（mine_lock只保护CLI miner）
- 源码位置: mcp_server.py, miner.py, sweeper.py:251

**HNSW索引漂移**
- SQLite元数据与HNSW `.bin` 文件不同步
- HNSW不受SQLite锁保护（Rust hnswlib内存映射）
- 导致segfault（chroma.py:52-131 quarantine_stale_hnsw）
- **现场验证：调用tool_diary_write时触发segfault**

**非原子修复操作**
- cli.py:263-351: delete collection → recreate → re-add
- 进程被杀会丢失数据

## 时间分析

重建需要重新计算所有embedding：
- 每drawer: embedding(5-30ms) + HNSW(1-5ms) + SQLite(1-2ms) = 10-35ms
- 18,866 drawer预计: 3-11分钟（正常情况）

## 预防建议

1. 运行mine前停止MCP server
2. 避免并发写入同一数据库
3. 修复后检查HNSW索引一致性
