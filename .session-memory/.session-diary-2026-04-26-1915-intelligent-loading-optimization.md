## 改进方案设计

### 策略选择

**用户建议对比：**
```
方案1：时间维度（近一周）
优点：时间范围明确，自动适应密度
缺点：文件数不可控，token波动大

方案2：容量维度（设定大小）
优点：token消耗可控，性能稳定
缺点：需计算总大小，需舍弃策略

选择：结合两种方案 ✓
- 主要：容量上限控制（稳定token）
- 辅助：时间倒序加载（优先最近）
- 灵活：自动适应数据密度
```

### 智能累积策略

**核心逻辑：**
```bash
MAX_TOTAL_SIZE_KB=30  # 总上限：30KB（约7500 tokens）
MAX_FILE_SIZE_KB=10   # 单文件上限：10KB
MIN_FILES=3           # 最少加载3个（保证覆盖）

while 遍历文件（按时间倒序）:
    if 文件数 >= MIN_FILES && 总大小 >= MAX_TOTAL_SIZE_KB:
        break  # 达到上限，舍弃最早的
    添加文件内容
    累积大小
```

**灵活覆盖：**
- 数据密度低时：可能加载7天前的文件（未达到上限）
- 数据密度高时：只加载最近几小时（达到上限）
- **自动平衡覆盖度和token消耗**
