## 改进实施

### 智能累积策略（结合两种方案）

**策略选择：**
- 主要：容量上限控制（稳定token消耗）
- 辅助：时间倒序加载（优先最近）
- 灵活：自动适应数据密度

**核心配置：**
```bash
MAX_TOTAL_SIZE_KB=30  # 总上限：30KB（约7500 tokens）
MAX_FILE_SIZE_KB=10   # 单文件上限：10KB
MIN_FILES=3           # 最少加载3个（保证覆盖）
```

**舍弃策略：**
- 按时间倒序遍历文件
- 累积到容量上限为止
- 超过上限舍弃最早的文件
- 保证最少加载MIN_FILES个

### 代码改动

**修改文件：** `~/.claude/hooks/mempal-sessionstart-wrapper.sh`

**改动对比：**
```bash
# 修改前（硬编码）
head -100 "$LATEST_DIARY"   # 最近1个
head -50 "$SECOND_DIARY"    # 上次1个

# 修改后（智能累积）
while 遍历文件（时间倒序）:
    if 文件数>=MIN_FILES && 总大小>=MAX_TOTAL_SIZE_KB:
        break  # 达到上限，舍弃最早的
    添加内容
    累积大小
```

**单文件过大处理：**
```bash
if 文件大小 > 10KB:
    head -150 "$diary_file"  # 只提取前150行
    添加提示："（提取前150行，原文件过大）"
```
