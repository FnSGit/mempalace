### 队列触发频率优化
**用户反馈（verbatim）：** "感觉有问题，几乎每次AI回复时候都会触发，而且会中断AI的回答。我只提一个问题，隔几分钟就出发了"

**问题诊断：**
- 根因：SAVE_INTERVAL=15太小，活跃对话工具调用频繁，快速计数到15
- 实际触发间隔：15-27次消息（符合设计，但用户感受"几分钟就触发"）
- 影响：频繁中断对话，用户体验差

**解决方案：**
- 修改 `mempal_save_hook.sh:55`
- 调整：SAVE_INTERVAL从15 → 30（触发频率降低50%）
- 效果：触发间隔延长到30-50次消息，用户感受明显改善

**验证：**
