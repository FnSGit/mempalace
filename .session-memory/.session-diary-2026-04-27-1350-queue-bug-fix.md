### 3. 发现严重Bug：队列数据静默丢失
**问题：** `palace.py:96` `get_collection()` 使用空handler处理队列
```python
# 修复前（bug）
queue.process_queue(lambda *args: None)  # 请求被claim后直接删除，数据未写入
```
**影响：** 1613个请求（包括1612个积压+1个测试）被静默丢弃
**修复：** palace.py:89-115，先获取raw collection，再用实际方法处理队列
```python
# 修复后
def _handler(operation, args, kwargs):
    if operation == "upsert": raw_collection.upsert(*args, **kwargs)
    elif operation == "delete": raw_collection.delete(*args, **kwargs)
queue.process_queue(_handler)
```
